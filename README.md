# ShopRecs – AI Powered Price Prediction & Recommendation System

## 🚀 Tech Stack
- Frontend: React (Vite)
- Backend: Node.js (Express)
- ML API: FastAPI (XGBoost)
- Scheduler: Node + Redis
- Database: MongoDB

## 🔥 Features
- 📊 Price Prediction using XGBoost
- 🤖 AI-based Buy/Wait Decision Engine
- 📦 Product Recommendation System
- ⏱ Scheduler for price tracking
- 📡 REST APIs (Node + FastAPI)

## 🌐 Deployment
- Frontend: Vercel
- Backend: Render
- ML API: Render / Cloud Run
- Redis: Upstash

## 📁 Project Structure
frontend/ – React UI  
backend-node/ – Main API  
backend-fastapi/ – ML model service  
scheduler/ – Background jobs
